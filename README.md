# RagHub

RagHub is a chatbot platform built around retrieval-augmented generation (RAG).

## Repository structure

```text
.
|-- apps/
|   |-- admin-web/       # Administration web application
|   `-- chat-widget/     # Embeddable chat widget
|-- backend/             # Backend services and APIs
|-- docs/                # Product and technical documentation
`-- infrastructure/      # Local and deployment infrastructure
```

This branch currently contains only the initial repository scaffold. Application
code and runtime configuration will be added in subsequent changes.
